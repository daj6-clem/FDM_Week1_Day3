Text-to-SQL lets an AI convert natural language questions into SQL queries. Risks incorrect facts or returns through incorrect queries.



Vector Retrieval is a RAG search technique that converts documents into vectors and uses them to find documents similar to a user question, so it can find relevant information even if the wording is different. It has a risk of incorrect context or policy guidance. It might miss the best policy or the most important policy or it might grab outdated policies, because similarity does not necessitate applicability.



Tool and automation allows the AI Agent to interact with external systems and complete predefined actions, like running queries or searching repositories or creating summaries. It risks unauthorized actions if the AI is jailbroken or if prompt injection or data leakage occur.



Validation: process of verifying that data meets expected requirements before it is used



Filtering: using rules to narrow down data to only what's relevant for a task



Allowlists: predefined sets of approved resources



Approval Controls: things that humans must review and authorize before they are executed
